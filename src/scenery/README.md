- `needle.png` et `green-tree2.png` : **Bleed**, Tree Collection v2.6, CC BY 3.0, https://opengameart.org/content/tree-collection-v26-bleeds-game-art ; portfolio original http://remusprites.carbonmade.com . Licence : https://creativecommons.org/licenses/by/3.0/ .
- `detail.jpg` : **Mysteryem**, GPL-2.0-or-later, https://opengameart.org/content/29-grounds-and-walls-and-water-1024x1024 .

Distribution utilisée : Trigger Rally 0.6.6.1 ; attributions amont conservées dans `../models/source/AUTHORS.txt`. Les images sources sont conservées sans modification. Le rendu applique une teinte, dispose le feuillage sur plusieurs plans croisés autour de troncs et branches en 3D, et mélange le détail du sol avec les matériaux générés. Il ne s’agit pas de scans d’arbres 3D. `scenery-data.js` embarque les images pour jouer sans réseau.
